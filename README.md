# Weekly Task Board

週2回（火曜・金曜）のSNS予約投稿オペレーション用ダッシュボード。

## セキュリティ方針（必読）

- **固有名詞禁止**：シート・特記事項・画面表示に個人名/ブランド名/商品名を書かない
- 本文はドライブ側に置き、シートには載せない
- シート・ドライブは「リンクを知っている人のみ閲覧」で限定公開
- HTMLは `noindex` + `robots.txt` で検索除外
- URLを第三者と共有しない

## セットアップ

### 1. Googleスプレッドシート作成
新規シートを作り、1行目に以下の列ヘッダを入れる：

```
週識別子 | バッチ | 投稿番号 | 媒体 | 投稿日 | 投稿時刻 | 曜日 | 本文ファイルURL | 素材フォルダURL | 予約ツールURL | 特記事項
```

**列の入力ルール**

| 列 | 例 | 備考 |
|---|---|---|
| 週識別子 | `2026-W17` | ISO週番号。月曜始まり |
| バッチ | `火曜` または `金曜` | 全角で統一 |
| 投稿番号 | `1`, `2`, `3`... | 週ごとに連番 |
| 媒体 | `Instagram` / `Facebook` / `Threads` / `note` / `YouTube` / `Flodesk` | 表記ゆれ注意。Flodeskはメルマガ予約配信 |
| 投稿日 | `2026/4/21` | |
| 投稿時刻 | `10:00` | |
| 曜日 | `火` | 1文字 |
| 本文ファイルURL | Googleドライブのリンク | |
| 素材フォルダURL | Googleドライブのリンク | |
| 予約ツールURL | Meta Business Suite等 | |
| 特記事項 | 固有名詞を含めない | 任意 |

### 2. CSVとして公開
ファイル → 共有 → **ウェブに公開** → 対象シートを選び、形式を **CSV** → 公開 → 表示されたURLをコピー。

### 3. config.jsにURLを設定
`config.js` の `csvUrl` に貼り付ける。

### 4. GitHub Pagesでホスティング
1. 新規プライベート/パブリックリポジトリを作成（リポジトリ名に固有名詞を含めない）
2. このフォルダの全ファイルをプッシュ
3. Settings → Pages → Sourceを `main` ブランチに設定
4. 公開URLを佳代子さんに共有（URL自体を第三者に渡さない運用）

## 使い方（佳代子さん向け）

1. ページを開くと今週の予約投稿一覧が表示される
2. 火曜バッチ・金曜バッチの順に1件ずつ処理
3. 各カードの「📄 投稿文」「📁 素材」「🔗 予約ツール」を開いて作業
4. 完了したらチェックボックスをオン（状態は自動保存）
5. すべて終わったら「✅ 全件完了を報告」ボタン
